# Brici
First year Microprocessors module assignment 'Brici'

For this assignment my partner and I received a grade of 93.33%.

This assignment consisted of using Assembly and C programing to create our own customized version of the game 'Brici'. We made use of a bread board, LEDs, an Arduino a microcontroller and other pieces of equipments to enable a user to physically play the game.
